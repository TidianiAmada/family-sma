# Fiche de lecture

Une page maximum. Fichier : `docs/lectures/<premier-auteur>-<année>.md`.

```
RÉFÉRENCE : (complète, avec DOI ou ISBN — vérifiée par bibliothecaire)
POURQUOI JE LA LIS : (quelle décision ou quel chapitre elle sert)
SECTIONS EFFECTIVEMENT LUES :
TEMPS PASSÉ :
CONCEPTS RETENUS (3 maximum) :
CE QUE JE DOIS SAVOIR EXPLIQUER À L'ORAL :
CITATION UTILE : « texte exact » (p. X)
DÉCISION DE CONCEPTION ASSOCIÉE : Fiche N / Dx / ligne de matrice
CHAPITRE ET SECTION DU MÉMOIRE :
CE QUE JE N'AI PAS LU ET POURQUOI :
STATUT : FOUNDATION | READ | PARTIAL | REFERENCE ONLY
```

## Règles
- Une citation entre guillemets n'est écrite que recopiée de la source, avec la page.
- Le statut est honnête : une référence parcourue est PARTIAL, pas READ.
- Après la fiche, mettre à jour la ligne correspondante de `docs/BIBLIOGRAPHIE.md` (statut, chapitres).
- Une référence sans décision associée ni chapitre est candidate à la suppression.
